## Featured Projects

### [TransAction](https://github.com/mindovermattr/TransAction)
Personal finance tracker that brings together accounts, transfers, budgets, analytics, subscriptions, and dashboard views in one full-stack app.

**Stack:** React 19, Vite 7, Tailwind CSS 4, Express 5, Prisma, PostgreSQL, JWT

### [Notice](https://github.com/mindovermattr/Notice)
Task and project management system with projects, task lists, subtasks, comments, authentication, and Yandex Disk integration.

**Stack:** Next.js 15, React 19, Redux Toolkit, NestJS, Prisma, PostgreSQL, JWT

### [vue-kanban](https://github.com/mindovermattr/vue-kanban)
Kanban board for task organization with drag-and-drop flows, card comments, history tracking, search, and access control.

**Stack:** Vue 3, TypeScript, Pinia, Ruby on Rails, PostgreSQL, Docker

### [sky](https://github.com/mindovermattr/sky)
SPA test assignment built around a product catalog flow, cart state management, and adaptive UI structure.

**Stack:** React, TypeScript, SCSS, Vite, React Router
